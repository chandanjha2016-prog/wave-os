## 📖 DESCRIPTION
**WAVE OS** is a real-time ocean wave monitoring and surf safety dashboard. 
It tracks wave height, wave period, direction, and risk levels across major Indian coastlines to help fishermen, surfers, and coastal communities stay safe.

This system is part of the **EARTH OS SUITE - 31 OS** built for Disaster Management, Climate and Life Saving applications.

**Key Purpose:** Early warning for high waves, surf condition analysis, and coastal safety alerts.

---

## ✨ FEATURES
- **Live Wave Data**: Wave Height, Period, and Direction monitoring
- **Risk Assessment**: 4-Level Risk System - LOW, MEDIUM, HIGH, EXTREME
- **Safety Alerts**: Automatic warnings for fishermen and tourists
- **Coastal Coverage**: 6 major Indian beaches monitored
- **Animated UI**: Ocean-themed design with live wave animation
- **Responsive Design**: Works on mobile, tablet and desktop
